# 微零密码箱 App —— 功能总览（重构基线）

> **[已归档 · 历史参考]** 本文描述旧 passmgr（SECP256K1 / AES-256-CBC 等）的功能清单，仅用于对照「要做哪些功能」。
> **不要采用其任何实现思路、架构或密码学方案**；当前实现以 [docs/01](../01-模块拆分与依赖选型.md)、[docs/09](../09-功能实现状态对照.md) 与代码为准。


> 目的：作为**功能重构的验收清单**。本文只描述「有哪些功能、每个功能做什么、边界在哪」，不涉及实现方式（架构、状态管理、UI 框架、接口路径均可重做）。
>
> 覆盖范围：`passmgr` Flutter 主客户端（iOS / Android）。来源为当前新架构 `lib/features/` 全部 12 个模块 + `lib/core/` + 路由表（66 个页面入口）逐项清点。
>
> 标注约定：
> - `[端]` = 端到端加密相关；`[本地]` = 纯本地能力，不经服务端；`[云]` = 依赖服务端。
> - 未标 **[待确认]** 的均为当前代码已实现的明确功能。

## 0. 全局能力（不挂在单个页面上）

| 能力 | 说明 | 边界 |
| --- | --- | --- |
| 端到端加密 | SECP256K1 密钥对 + AES-256-CBC；服务端仅存密文 | 私钥永不离开设备（除用户主动备份产物） |
| 身份与密钥分离 | 「登录态」与「保险库解锁态」是两个独立状态 | 登录 ≠ 解锁；账户锁定 ≠ 保险库锁定 |
| 会话状态机 | signedOut / awaitingUnlock / unlocked / locked / accountLocked / expired / recovering | 见 §1.4 |
| 离线优先 | 本地加密快照缓存；写入先落本地，异步同步云端；离线可读可写 | 同步状态机：local / offline / syncing / synced / attention |
| 自动锁屏 | 退后台超时自动锁定保险库；可选锁屏按钮、密码隐藏 | 阈值可配置（1/3/5/10/15/30/60 分钟） |
| 隐私合规 | 首启隐私政策同意弹窗；同意前不发任何网络请求；不接入第三方统计/广告 SDK | 协议文案以官网为唯一事实来源 |
| 国际化 | 简中 / 繁中 / 英文三语，手动维护 | 全端覆盖 |
| 外观 | 主题模式：跟随系统 / 浅色 / 深色 | 见 §9 |
| 截图保护 | 系统级截屏/录屏防护开关 | 默认开启 `[本地]` |
| 安全剪贴板 | 复制敏感字段后定时自动清空剪贴板 | 默认 60 秒，可配置 `[本地]` |
| 锁屏隐私 | 隐藏密码（默认开）、隐藏通知内容 | 见 §8.4 |
| 深链 / 路由守卫 | 账户锁定、会话过期、登录/解锁互斥的强制改道 | 业务页在被锁定时不可停留 |
| 应用内更新 | 冷启动检查新版本、强制/可选升级、下载安装、SHA-256 校验 | `[云]` |

## 1. 启动、登录与身份

### 1.1 首次启动与引导
- 启动页（品牌展示 + 状态解析）。
- 首次启动：隐私政策 + 用户协议同意弹窗；不同意则退出。
- 引导流程（onboarding）与「已完成引导」标记。
- 底部入口：登录、注册、找回密码、打开协议/隐私。

### 1.2 注册 `[云]` `[端]`
- 账号注册（账号/密码，具体字段以服务端为准）。
- 注册成功 → **生成 SECP256K1 私钥对**。
- 注册成功后强制进入**私钥备份页**（见 §4.3），未确认备份不得进入主应用。

### 1.3 登录 `[云]` `[端]`
- 账号 + 密码登录。
- 登录分支（服务端驱动，前端分流）：
  - `authenticated`：直接进入保险库解锁。
  - `deviceVerification`：**新设备验证**（见 §1.5）。
  - `accountUnlock`：账户被锁定（见 §1.6）。
  - `accountBanned`：账号封禁（见 §1.7）。
  - `keyUpgrade`：**密钥升级**（见 §1.8，老密钥版本迁移）。
  - `privateKeyImport`：**私钥导入**（见 §1.9，本机无本地私钥时从用户手中恢复）。
- 找回密码入口。
- 注册入口。
- 协议 / 隐私政策外链。

### 1.4 会话状态机（全局）
| 状态 | 含义 | 落点 |
| --- | --- | --- |
| signedOut | 无持久化登录 | 启动页/登录页 |
| awaitingUnlock | 已登录、本地有私钥、待解锁保险库 | 解锁页 |
| unlocked | 保险库已解锁 | 主应用 |
| locked | 保险库被手动/超时锁定 | 解锁页 |
| accountLocked | 账户级锁定（管理员或密码错误自动） | 账户解锁页 |
| expired | 登录被踢出 / 会话过期（501） | 强制回登录页 |
| recovering | 已登录、服务端有密钥但本机无私钥 / 本地快照不可读 | 私钥恢复页 |

### 1.5 新设备验证 `[云]`
- 展示服务端下发的验证渠道提示（有邮箱 / 有手机）。
- 收码渠道由**登录账号格式**推导（非主渠道偏好）。
- 验证通过 → 进入保险库解锁。
- 流程中可转：账户锁定 / 密钥升级 / 私钥导入。

### 1.6 账户解锁 `[云]`
- 两种锁定来源：`0` 密码错误自动锁、`1` 管理员手动锁。
- **管理员锁**：隐藏自助解锁表单，引导联系客服；展示锁定理由、锁定时间。
- **自动锁**：允许自助解锁；展示自动解锁倒计时（lockExpireTime）。
- 展示信息：锁定来源、理由、锁定时刻、自动解锁时间、是否允许自助解锁。
- 解锁成功落点：锁定前已解锁 → 回保险库；否则 → 回解锁页。
- 冷启动探测即识别锁定（进入解锁页前先探测），避免先渲染错误表单。
- 账户被锁定时：仅放行解锁链路与登录/启动/找回密码，业务页强制改道。

### 1.7 账号封禁
- 展示封禁理由（服务端下发，可空）。
- 返回登录入口。

### 1.8 密钥升级 `[云]` `[端]`
- 老版本密钥的迁移升级流程。
- 升级后若需新备份 → 强制进入私钥备份页。

### 1.9 私钥导入（本机恢复）`[云]` `[端]`
- 用户输入 Secret Key 导入。
- 校验规则（`[本地]`，独立规范，见 §4.4 解析规范）。
- 导入成功 → 进入保险库。
- 会话终止 → 回登录页。

### 1.10 保险库解锁（App 解锁）`[端]`
- 账号密码 / 保险库密钥解锁。
- 支持**生物识别解锁**（指纹/面容，需已启用于设置中）。
- 一键锁定按钮（来自安全设置 `hasLockKey`）。
- 解锁响应可能返回账户锁定 → 带锁定信息来源转账户解锁页。
- 找回密码入口。

### 1.11 私钥恢复页 `[端]`
- 当服务端有密钥、本机无本地私钥，或本地快照不可读时的恢复引导。

### 2.1 App 外壳

## 3. 密码箱核心（Vault）

### 3.1 条目内容模型
- 条目名称、所属分类、收藏标记。
- 动态字段列表，字段类型：
  - `password` 密码（敏感）
  - `secret` 密文（敏感）
  - `text` 文本
  - `date` 日期
  - `image` 图片（本地路径 / 远程地址；含加载失败态）
- 标签（多标签）。
- 应用绑定（appIds，用于自动填充匹配）。
- 网站域名绑定（webDomains，用于自动填充匹配）。
- 头像/图标。
- 时间戳（创建、更新）。
- 归属：spaceId（工作区）、collectionId（集合）、keyOwnerId（密钥归属人）。
- 版本号 itemVersion（冲突检测用）。
- 删除标记 isDeleted。
- 待同步标记（本地负 ID 表示 pending）。

### 3.2 新建 / 编辑条目
- 字段增删改；必填校验、最大长度校验、键盘类型。
- 图片字段：从相册选择、裁剪/压缩、预览、清除。
- 分类选择、标签多选（含数量）。
- 收藏开关。
- 应用绑定 / 域名绑定编辑。
- TOTP 字段（见 §3.4）。
- 模板选择（见 §3.3）。
- **草稿恢复**：未保存的编辑草稿可恢复。
- 编辑保存：刷新已有详情页而不堆叠重复页面。
- 冲突检测：基于 itemVersion 与 baseValue 的乐观并发。

### 3.3 条目模板
- 预置模板列表（按分类给出字段集合）。
- 从模板创建条目。

### 3.4 TOTP（动态验证码）
- 绑定 TOTP 密钥（扫码 / 手动）。
- 实时展示动态验证码与倒计时。
- 编辑模式下新增/替换 TOTP。
- 二维码扫描组件（相机扫码）。

### 3.5 条目详情
- 展示全部字段；敏感字段默认隐藏，点击显示。
- 复制到安全剪贴板（自动清空）。
- 字段图片查看。
- 编辑入口、删除入口。
- 归属工作区/集合标识。
- 待同步状态提示。

### 3.6 组织与检索
- 全部条目页（含搜索框，URL 可带 query）。
- 收藏页。
- 分组页（树形）→ 分组内条目页。
- 分类页 → 分类内条目页。
- 标签页 → 标签内条目页。
- 首页板块自定义页（板块排序、显示/隐藏、是否展示）。

### 3.7 导入 / 导出（纯本地）`[本地]`
**导入：**
- 支持格式：通用 CSV、Chrome CSV、Bitwarden CSV、KeePass CSV、1Password `.1pux`、本项目加密包 `.wljbak`。
- 文件选择（扩展名白名单：csv / txt / 1pux / wljbak）。
- 格式自动识别 + 格式守卫（拒绝错误文件）。
- 字段映射：源列 → 目标字段（标题/用户名/密码/URL/备注/TOTP/文件夹/收藏/忽略）。
- 预览（最多 20 条）、解析警告、跳过行数统计。
- 重复处理策略：跳过 / 覆盖 / 两者都保留。
- 目标分类选择（或按「文件夹」列匹配，失败回退默认分类）。
- 进度展示（已处理/总数/导入/覆盖/跳过/失败）。
- 结果汇总（成功/覆盖/跳过/失败 + 首条错误原因）。
- 导入历史（源文件名、路径、格式、条数、时间；可跳转文件所在目录）。
- 导入内容本地加密后写入，全程不经服务端。

**导出：**
- 格式：加密备份包 `.wljbak`（本机密钥加密）、明文 CSV（迁移到他端）。
- 进度展示。
- 结果：文件名、路径、条目数、跳过数、字节数、可读大小、保存位置、是否落盘到用户位置。
- 导出历史（仅本地留存，不含明文）。
- 打开文件所在目录 / 分享。

### 3.8 回收站
- 已删除条目列表。
- 恢复 / 彻底删除 / 清空回收站。

### 3.9 冲突处理
- 本地与服务端版本冲突列表。
- 冲突解决（保留本地 / 保留远端 / 合并）**[待确认：具体策略以现有实现为准]**。

### 3.10 同步与离线
- 同步状态：local / offline / syncing / synced / attention。
- 待同步条数。
- 最近同步时间。
- 需要关注时提示（离线、冲突）。
- 操作队列异步上云。

### 3.11 排序 / 展示
- 分组按 sortOrder 稳定排序；分组条目数含后代汇总。
- 首页板块按 sort 排序。

## 4. 密钥与备份

### 4.1 私钥管理页
- 展示本机是否持有私钥。
- 备份状态（本地 + 云端双来源，并集判定）。
- 最近备份时间（云端优先，回退本机）。
- 最近备份方式（完成备份 / 重新生成 / 二次确认 / 复制 / 下载图片 / 导出 PDF）。
- 云端备份记录条数。
- 入口：私钥备份、私钥更换。

### 4.2 私钥查看 `[端]`
- 查看私钥（需再次验证）。
- 触发备份流程。

### 4.3 私钥备份页 `[端]` `[本地]`
- 展示 Secret Key（规范形态 44 字符）。
- **备份卡**：700×900 逻辑尺寸，2x 导出 1400×1800 图片。
- 备份凭证文案：品牌、凭证标题、副标题、规范页脚、核心警告、敏感文件提示、恢复失败提示、存储建议。
- 备份产物：
  - 复制私钥到剪贴板（安全剪贴板）。
  - 保存备份图片到相册。
  - 导出 PDF。
  - 系统分享（可选）。
- 登录地址印在凭证上：`www.passmgr.com/auth`。
- 文件名规则：`wljpassmgr-emergency-kit-<账号安全片段>.<ext>`。
- **二次确认**：重新输入私钥比对（字节级比对，容错零宽字符/缺 `=`/历史 31 字节）。
- 备份完成/各旁路动作上报云端备份历史（失败不阻断本地产物，但完成备份上报失败要明确提示）。

### 4.4 Secret Key 解析规范（跨端共用）`[本地]`
- 归一化：剥离零宽空格/零宽非连接符/零宽连接符/BOM 及空白。
- 字符集与补位校验 → Base64 解码。
- 拒绝原因（封闭集合，新增需升版本）：`EMPTY` / `INVALID_CHARSET` / `INVALID_ENCODING` / `TOO_LONG` / `OUT_OF_RANGE`。
- 左补零至 32 字节；范围校验：`0 < scalar < secp256k1 阶`。
- 历史兼容：31/30 字节私钥左补零，标记 `padded`。
- 规范版本号 v1；三端互认靠共享 JSON 测试向量。
- **禁止用字符串长度判合法性**。

### 4.5 私钥更换 `[端]`
- 生成新私钥并替换。
- 更换后强制重新备份（动作类型记为「重新生成」）。
- 上报备份历史。

### 4.6 备份引导页
- 引导用户完成/补做私钥备份。

## 5. 安全中心（Security）

### 5.1 安全总览
- 安全评分。
- 任务清单（每项：标题、描述、完成态、图标、点击跳转）。
- 已完成任务数 / 总任务数。
- 风险项列表 + 总数。
- 宫格入口：生物识别、自动锁定、自动填充、私钥、私钥管理、通用设置、设备管理、账户安全、安全体检。

### 5.2 安全体检（密码健康）
- 健康报告：总分（0–100）、最近检查时间、是否过期（24 小时）。
- 检查维度评分（扣分项）：
  - **泄露检测**（breach，单次封顶 50）
  - **弱密码**（weak，封顶 24）
  - **密码复用**（reuse，封顶 20）
  - **长期未更新**（stale，封顶 15）
  - **设备环境**（environment，封顶 30）
  - **设置项**（settings，封顶 30）
- 泄露检测状态：未运行 / 正常 / 不可用 / 已跳过。
- 统计：已扫描密码数、密码字段数、不可读条目数。
- 发现项（Finding）：分类（保险库/泄露/环境/设置）、严重度（严重/高/中/低）、标题、描述、图标、关联条目、数量。
- **忽略（snooze）**：可将某发现项暂停一段时间。
- 发现项动作：无 / 打开条目 / 打开体检详情 / 生物识别 / 自动锁定 / 自动填充 / 私钥 / 通用设置 / 系统设置。
- 体检详情页（按发现项/分类下钻）。
- 设备环境探测项：
  - 是否支持探测
  - 调试器附着
  - 模拟器
  - ADB 开启
  - 开发者选项
  - 设备安全（锁屏）
  - 是否被攻破（root/越狱）

### 5.3 生物识别设置
- 是否支持、是否已录入、是否已启用、可用识别类型。
- 启用条件：支持且已录入。
- 开关生物识别解锁。

### 5.4 自动锁定设置
- 退出即锁定（lockOnExit）。
- 自动锁定时间：1/3/5/10/15/30/60 分钟。
- 显示锁屏按钮。
- 隐藏密码（默认开）。

### 5.5 自动填充引导

## 13. 重构时需要显式保留的「隐性契约」

这些不是页面，但重构极易丢失，必须逐条落位：

1. **私钥与登录态解耦**：登录成功不等于保险库解锁；账户解锁不等于保险库解锁。
2. **账户锁定是请求级门禁**：会话仍有效（不需重登），但业务接口返回 423；前端必须强制改道且只放行自助解锁链路。
3. **管理员锁 vs 自动锁**：来源缺失时保守按管理员锁处理（隐藏注定失败的自助表单）。
4. **冷启动锁定探测**：进入解锁页前先探测，避免首帧渲染错误表单；探测只做一次。
5. **会话过期（501）优先级最高**：清本地登录并回登录入口，不卡在启动加载。
6. **离线优先**：写入先本地、异步同步；离线可读可写。
7. **待同步条目用负 ID 表示**。
8. **乐观并发**：itemVersion + baseValue，冲突进冲突页。
9. **Secret Key 只用统一解析入口校验**，禁止长度判断。
10. **备份三来源一致性**：本地记录、云端状态、动作枚举三端逐值对齐；本地/云端取并集判备份。
11. **服务端时间无时区**：按东八区解析为本地时间展示，回读校验防脏值。
12. **截图保护 / 剪贴板清空 / 隐藏密码**默认策略不可在重构中反转默认值。
13. **同意隐私政策前不发起网络请求**。
14. **不接入第三方统计 / 广告 SDK**。
15. **邀请码方向不可混用**：我的邀请码（往外发）vs 我补填的邀请人码（别人给我的），后者一次性不可改绑。
16. **积分兑换幂等**：clientMutationId 必填，重试沿用同一值。
17. **组织密钥信封**：服务端只存密文信封，成员密钥分发端到端完成。
18. **截图/录屏保护与锁屏按钮由安全设置开关驱动**，`hasLockKey` 决定是否展示一键锁定。
19. **备份上报失败必须提示**（本地产物已生成，但云端没记上会导致换设备看不到记录）。
20. **法律文案以官网为唯一事实来源**，App 内不做本地副本。
