## 3. 隐私声明

### 3.1 Apple 隐私清单 —— `app/ios/Runner/PrivacyInfo.xcprivacy`

| 数据类型 | 关联用户 | 用于追踪 | 目的 | 说明 |
|---|---|---|---|---|
| 邮箱地址 | 是 | 否 | App 功能 | 仅开启云同步后；服务端存 HMAC 索引 + AES-256-GCM 密文 |
| 设备 ID | 是 | 否 | App 功能 | 随机生成的设备标识，用于新设备验证与设备管理 |
| 其他用户内容 | 是 | 否 | App 功能 | 用户自填的设备名 |

保险库内容端到端加密、开发者无法读取，按 Apple 定义不属于「收集」。Required Reason API：`SystemBootTime`（35F9.1，Rust `Instant`）、`FileTimestamp`（C617.1，应用容器内文件元数据）。

### 3.2 Google Play 数据安全表

与 3.1 一致：收集邮箱、设备 ID（仅开启同步时），均**传输加密**、**可请求删除**（开启同步后「设置 → 危险操作 → 注销云端账户」即删除云端全部数据）；不与第三方共享；不用于广告或分析。

### 3.3 权限说明

| 权限 | 平台 | 用途 |
|---|---|---|
| 网络（Android `INTERNET`、macOS `com.apple.security.network.client`） | 全部 | 同步（可不开启，纯本地使用） |
| 生物识别（`USE_BIOMETRIC` / `NSFaceIDUsageDescription`） | Android / iOS | 快速解锁（可选）；macOS Touch ID 与 Windows Hello 无需额外声明 |
| 相机（`CAMERA` / `NSCameraUsageDescription`） | Android / iOS | 扫描 TOTP 二维码（可选；扫码页只在 Android / iOS 提供） |

| 自动填充服务（`BIND_AUTOFILL_SERVICE`） | Android | 用户在系统设置中选择 VaultOne 后，在应用 / 浏览器登录框提供「用 VaultOne 填充」与保存提示；服务只识别表单字段，不读取其他应用内容 |

自动填充现状：**Android 已实现** `AutofillService`（Android 8+ 填充，9+ 保存提示；设置页「自动填充 → 去设置」引导开启）；**iOS 尚未实现** AutoFill Credential Provider 扩展，iOS 提交时不要声明该能力。

### 3.4 浏览器扩展（Chrome 应用店 / Edge 加载项）

| 项 | 内容 |
|---|---|
| 源码 / 打包 | `extension/`；CI `extension` 任务产出 `vaultone-extension.zip`（不含 `test/`） |
| 单一用途说明 | 连接本机 VaultOne 桌面端，在网页登录表单中填充与保存 VaultOne 中的登录信息 |
| 权限理由 | 见 `extension/README.md`「权限说明」 |
| 数据使用披露 | 不收集、不上传任何数据；网页地址与表单中的用户名 / 密码只经 Native Messaging 发往本机桌面端 |
| 上架后 | 把商店分配的扩展 ID 追加到 `crates/vault-proto/src/lib.rs` 的 `EXTENSION_IDS`，并把 `VAULTONE_EXTENSION_URL` 设为商店页地址后重新发布桌面端 |

## 4. 加密出口合规

使用标准加密算法（AES-256-GCM、Argon2id、HKDF、SRP-6a、TLS），不含专有算法：

- `app/ios/Runner/Info.plist` 设 `ITSAppUsesNonExemptEncryption = false`：只使用公开标准算法（RustCrypto 实现 + rustls），且仅用于保护用户自身数据，按豁免情形申报，提交时无需上传出口合规文件。`app/macos/Runner/Info.plist` **未设置**该键，Mac App Store 提交时需在 App Store Connect 中回答出口合规问题（或补上该键）。
- 若面向法国分发，需另行确认当地加密进口申报要求。
- 源码以 AGPL-3.0 公开，适用 EAR §742.15(b) 公开源码通知。

## 5. 审核说明（提交给审核员）

- 应用无需注册云端账户即可完整使用（本地保险库）：创建保险库时填写的邮箱只以密文保存在本机，不联网；云同步为可选功能，审核时可不开启。
- 若审核需要演示同步，提供测试服务器地址与已注册的演示账户（含主密码与 Secret Key），并在备注中说明 Secret Key 的作用。
- 说明应用无法找回主密码：这是零知识设计的必然结果，Recovery Kit 为唯一恢复途径。
