## 1. 状态口径

| 状态 | 含义 |
|---|---|
| **已实现** | 主要调用链完整（UI → FRB → 内核 / 服务端），非孤立函数或占位 |
| **已实现（未真机验收）** | 代码链路完整，但只在协议级/编译级验证，未在真实设备或浏览器跑通 |
| **部分** | 有基础能力，缺基线的子功能 |
| **缺失** | 未找到对应实现 |
| **已排除** | 明确不做，不计欠账 |
| **替代** | 由当前架构的等价机制承载，不作为待重写功能 |

**不采用的基线内容**（有意决策，非欠账）：SECP256K1/AES-CBC 旧密码学、旧 Base64 Secret Key 规范、负 ID 约定、东八区无时区时间、"我的/首页"四 Tab 形态、66 路由逐页对照。当前实现为 Aragon2id/AES-256-GCM/SRP-6a、Crockford Base32 Secret Key、UTC、桌面侧栏分区 + 手机底部导航。
