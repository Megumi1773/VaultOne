# 09 · 功能实现状态对照

> 本文按 [基线功能总览](archive/App功能总览-重构基线.md) 的章节逐条对照**当前代码实际实现**，是功能进度的唯一口径。
> 判定以代码为准，不采信历史计划措辞；**计划、排期、目标方案已归档**，见 [archive/09-开发计划与排期-已归档.md](archive/09-开发计划与排期-已归档.md)。
> 核对日期 2026-10-01；代码基线 `DeepSeek41 / 3071c21`。

## 1. 状态口径

| 状态 | 含义 |
|---|---|
| **已实现** | 主要调用链完整（UI → FRB → 内核 / 服务端），非孤立函数或占位 |
| **已实现（未真机验收）** | 代码链路完整，但只在协议级/编译级验证，未在真实设备或浏览器跑通 |
| **部分** | 有基础能力，缺基线的子功能 |
| **缺失** | 未找到对应实现 |
| **已排除** | 明确不做，不计欠账 |
| **替代** | 由当前架构的等价机制承载，不作为待重写功能 |

**不采用的基线内容**（有意决策，非欠账）：SECP256K1/AES-CBC 旧密码学、旧 Base64 Secret Key 规范、负 ID 约定、东八区无时区时间、"我的/首页"四 Tab 形态、66 路由逐页对照。当前实现为 Aragon2id/AES-256-GCM/SRP-6a、Crockford Base32 Secret Key、UTC、桌面侧栏分区 + 手机底部导航。

## 8. 隐性契约（基线 §13，20 条）

成立 9 条：私钥/登录态解耦（仅 UI 层）、离线优先、Secret Key 统一解析、同意前不联网、无第三方统计 SDK、乐观并发、冷启动单点探测、默认值未反转、法律文案外链。

缺失/部分 11 条：账户锁定 423（§13.2）、管理员锁 vs 自动锁（§13.3）、会话过期 501 语义（§13.5）、负 ID（§13.7，改用 dirty 位）、备份三来源一致性（§13.10）、东八区时间（§13.11，已统一 UTC）、邀请码方向（§13.15）、积分兑换幂等（§13.16）、组织密钥信封（§13.17，已排除）、hasLockKey 开关（§13.18）、备份上报失败提示（§13.19）。

**三处已静默偏离基线且无书面变更记录**：负 ID、东八区时间、Secret Key 规范。

## 9. 页面数与路由

当前 `app/lib/src/ui/screens/` 共 15 个页面文件（backup_dialog、cloud_setup、conflicts、feedback、generator、home、item_detail、item_editor、item_list、onboarding、qr_scan、security、settings、sign_in、unlock），另有 Android 自动填充独立界面。基线 66 路由不逐条对照（架构不同，见 §1）。
