# 13 · 云账户与本地优先保险库

> 2026-10-01 用户决策。Java 是客户端账户及在线业务的唯一新增后端。本文描述本批行为契约，验收以 docs/11 为准。

## 边界

- 新注册、登录、新设备批准、云账户恢复、改主密码、设备管理、安全操作日志、反馈等在线业务直接调用 Java；不再提供“纯本地创建账户 / 可选开启或关闭云同步”的产品模式。
- 主密码、Secret Key、Vault Key 及条目明文仍只在客户端。走服务端登录不是发送主密码；继续使用既有 SRP-6a 和客户端密封格式。
- 保险库条目（密码、卡片、笔记、身份、自定义字段、TOTP）继续 SQLite 本地优先：先在本机加密落库，立即可读写，在线时后台上传密文并增量拉取。冲突仍在本机三方合并/人工裁决；失败保留待同步条目，不以远端整库覆盖本机。
- 已登录设备的锁定/解锁仍是本机密钥访问控制，不是每次输入主密码都重新注册/登录。断网或云会话过期不删除条目、不阻止合法本地解锁；网络业务明确报错，不伪装本地成功。
- 密码生成、TOTP、加解密、导入/导出、剪贴板和本机安全设置本质上是客户端能力，继续本机执行，不上传秘密来“云化”。本批不引入尚未存在的通知/积分等新业务；以后此类在线业务只接 Java。

## 注册与旧数据

注册中的本机加密材料只是待确认的云账户草稿，不等于账户注册成功。只有服务端完成确认并建立设备会话后才进入恢复套件确认和保险库。失败需保留可恢复材料并提供重试；响应丢失时必须证明是同一账户再恢复会话，不能将任意 email_taken 当作成功。

既有纯本地保险库不得清空。升级后引导用现有账户标识/密钥注册到 Java；同邮箱不同云账户不得覆盖或合并。旧连接地址与新 Java 地址不同时暂停自动联网，显式重新认证并核对账户/保险库标识后才换绑；目标服务没有原账户时保留原连接和本机待同步数据，不自动迁移生产数据。

## 网络与同步

- 本机 Java dev 地址为 `http://127.0.0.1:9777`；仅回环开发例外允许 HTTP。生产构建必须显式提供 HTTPS 服务地址，不能把本机地址当作官方生产服务，也不尝试 HTTPS 失败后降级 HTTP。
- 隐私同意前不发业务请求。登录/注册/恢复提交后取消只取消界面接收，不能声称撤回已经执行的远端操作。
- 条目编辑去抖同步、解锁后同步、定期重试沿用原机制。网络错误保留本地脏行；认证错误要求重连，不能靠关闭同步变成纯本地账户。
- 在线账户操作与条目同步分离：改主密码只有云端凭据确认后报告成功，不再排入普通条目同步假装“稍后生效”；恢复从服务端取恢复包并轮换凭据，旧会话失效。退出先由 Java 撤销会话，再锁定本机；绑定/条目/游标保留，离线解锁不等于再次登录云端。
- 恢复/改密/注册的客户端落盘与云提交不是分布式事务；明确保留重试材料及恢复路径，不以清空本机库补偿远端状态。

## 验收重点

真实 Java + PG/Redis + Rust 客户端注册/登录/同步/恢复；注册断网与重试/响应丢失、同邮箱不同身份拒绝、旧本地库保留、显式换绑错误目标拒绝；已登录账户离线条目可读写且恢复连接后补传；UI 不再有纯本地创建及关闭同步入口；隐私/锁定/取消的晚到结果门禁。
